Браузерный инструмент для быстрого создания диаграмм с предустановленными стилями.

- **Низкий порог входа:** готовые стили
- **Приватность:** обработка на клиенте, данные хранятся на устройстве
- **Экспорт в PNG:** с прозрачным фоном или без
- **Будущая функция:** экспорт анимированных схем

## Стек
- Интерфейс: Angular
- Графика: Konva.js (Canvas)
